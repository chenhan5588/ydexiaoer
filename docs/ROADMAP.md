# PrintOS — Roadmap

## V1.0 — 图片质检 + AI 修复 + 订单批量处理（当前阶段）

### ✅ 已交付
- [x] 图片质量检测（分辨率、清晰度、噪点、对比度、颜色均匀度、边缘质量）
- [x] V1 修复引擎（Pillow — 效果有限）
- [x] V2 修复引擎（OpenCV + rembg — 已编写，待部署）
- [x] 亚马逊订单 ZIP 自动解析（嵌套解压、尺码/效果图/来图提取）
- [x] Excel 导出（嵌入效果图 + 来图）
- [x] 登录验证（密码页）
- [x] 模块化代码架构（modules/auth|quality|repair|orders）

### 🔧 进行中
- [ ] V2 修复引擎部署到服务器（OpenCV 超分 + CLAHE + rembg 去背景）
- [ ] 登录页面上线

### 📋 待开始
- [ ] Nginx + 域名 + HTTPS（Let's Encrypt）
- [ ] 批量订单一键质检 + 修复 + 导出
- [ ] 操作日志（谁在什么时间处理了什么订单）
- [ ] 异常图片人工审核队列

## V2.0 — 排版 + 美工面板

- [ ] 拖拽式排版画布（30cm × 30cm，300DPI 预览）
- [ ] 烫画位置预览（马克线、出血线、安全区）
- [ ] 排版模板库（保存/加载常用布局）
- [ ] 多图批量排版（一个订单多件商品自动排列）
- [ ] 导出 PDF/PNG 交付文件

## V3.0 — AI 智能排版

- [ ] 基于产品类型的智能布局推荐
- [ ] 图案自动缩放/旋转适配热转印区域
- [ ] 配色建议（图案与底衫颜色匹配）
- [ ] 历史订单学习 → 自动推荐排版方案

## V4.0 — 全流程自动化

- [ ] 客户上传 → 自动质检 → AI 修复 → 自动排版 → 美工审核 → 一键交付
- [ ] 接入亚马逊/Shopee/TikTok 订单 API
- [ ] 数据仪表板（日处理量、质检通过率、修复效果统计）
- [ ] 多人协作权限系统
