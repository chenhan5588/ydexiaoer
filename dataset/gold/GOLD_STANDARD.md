# Gold Standard — 修图样本规范

## 样本来源

从真实客户来图中精选，由美工手工修图完成。12 组配对覆盖所有常见变换类型。

## 输出标准

| 参数 | 值 |
|---|---|
| 格式 | PNG (RGBA) 透明底 |
| 尺寸 | 5906 × 5906 px |
| DPI | 300 |
| 对应印刷尺寸 | ~50 × 50 cm（留了 30cm 烫画区域的边距） |

## 变换类型分类

### A. 去背景 → 透明底（最常见）
before1→after1, before4→after4, before5→after5, before8→after8, before9→after9

- 黑色/深色/纹理背景 → 完全去除
- 只保留主体图案
- 输出 RGBA 透明 PNG

### B. 实物照片 → 数字重绘
before6→after6

- 去掉摩尔纹、反光、拍照产生的颜色偏差
- 重绘为干净的数字风格
- 保持原始颜色信息

### C. 截图 → 主体提取
before10→after10

- 去掉 UI 元素（状态栏、浏览器 UI）
- 去掉水印（如 itstrendbuzz.com）
- 提取核心图案主体

### D. 放大 + 透明底
before2→after2, before3→after3, before7→after7, before11→after11, before12→after12

- 原始小图（1024px 等）放大到 5906×5906
- 同时去背景变透明

## 使用方式

- **训练参照**：每个 before 是输入，对应的 after 是期望输出
- **质量评估**：用 SSIM / LPIPS 对比修复结果和 gold 标准
- **规则推导**：分析美工手工操作的模式，转化为自动化 pipeline
